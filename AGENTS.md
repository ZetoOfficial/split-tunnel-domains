# Repository Instructions

- Source files are in `countries/*/*.txt`.
- Generated subscription files are in `lists/*.txt`.
- For v1, only populate `countries/russia`.
- Keep `countries/other` as a placeholder.
- Do not add Python.
- Keep scripts POSIX sh compatible.
- Run `sh scripts/validate.sh` and `sh scripts/build.sh` before finishing changes.
- Do not add wildcard entries.
- Do not add non-Russia domains in v1 unless explicitly requested.
